# primum

Prioritized work items as plain markdown files, from the command line, for
any number of projects. primum is changing fast; the documentation follows
the current release.

Documentation: <https://aegea-dev.github.io/primum/>

## Install

```bash
brew install aegea-dev/tap/primum
```

or with the install script, which verifies the download's checksum:

```bash
curl -fsSL https://raw.githubusercontent.com/aegea-dev/primum/main/install.sh | sh
```

or, with a Rust toolchain:

```bash
cargo install primum --locked
```
