## Why

A project connected to a GitHub repository keeps its items and that repository's issues in step in both directions, automatically. GitHub's closing keywords work as always (`Fixes #123` closes the issue and the item), and primum ids work in them too (`Fixes TODO:87`). Optional: nothing changes for a project that is not connected.

Builds on KILLER:2: GitHub is one more side of the same three-way merge, and a real disagreement is the same kind of conflict. See the spec and plan beside this item.
