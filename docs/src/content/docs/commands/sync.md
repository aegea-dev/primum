---
title: primum sync
description: Pull, merge and push now.
---

```bash
primum sync
```

Fetches the remote, merges and pushes. With a remote set (and not `--manual`), every change
already syncs by itself; this is for a manual remote or to check right away.

Prints what came in and went out, and conflicts left. See
[history and sync](/guides/history-and-sync/).
